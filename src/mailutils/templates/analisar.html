O que este ecrã procura

Os sinais que se veem sem abrir o email, e os que só se vêem depois de o abrir. Nenhum deles é uma prova.

  • Cabeçalhos — quem diz ter enviado, para quem, e se os domínios concordam entre si.
  • Texto — assunto, urgência, e a pressão para agir depressa.
  • HTML — scripts, texto escondido, CSS suspeito.
  • Ligações — quantas, para que domínios, e se há encurtadores.
  • Imagens — pixels de rastreio, e a relação com o texto.
  • Estrutura — tamanho, anexos, partes sem conteúdo.

Os pesos são diferentes dos da assinatura, e é de propósito. Uma assinatura com seis ligações é um sinal; um email com seis ligações é um email normal.
